# AI Data Scientist

A functional AI-powered data analysis platform built with modern technologies.

## 📋 Description

This application provides a comprehensive suite of data analysis tools powered by machine learning. Upload CSV datasets and perform statistical analysis, regression modeling, classification, and outlier detection with interactive visualizations.

## 🚀 Live Demo

**Frontend**: https://agentic-24f8ca38.vercel.app

## Features

- **CSV Data Upload**: Upload and manage datasets
- **Descriptive Statistics**: Comprehensive statistical analysis with correlation matrices
- **Linear Regression**: Train and evaluate regression models with visualization
- **Random Forest Classification**: Classification with feature importance analysis
- **Outlier Detection**: Z-score based outlier identification
- **Interactive Visualizations**: Charts and graphs powered by Recharts

## Tech Stack

### Frontend
- React 18 with TypeScript
- Vite for fast development and building
- Tailwind CSS for styling
- shadcn/ui component library
- Recharts for data visualization
- Lucide React for icons

### Backend
- FastAPI for high-performance API
- Pandas for data manipulation
- NumPy for numerical computing
- Scikit-learn for machine learning
- Python 3.12

## Local Development

### Backend
```bash
cd ai-data-scientist/backend
poetry install
poetry run fastapi dev app/main.py
```

### Frontend
```bash
cd ai-data-scientist/frontend
npm install
npm run dev
```

## Usage

1. Visit https://agentic-24f8ca38.vercel.app
2. Upload a CSV file with your dataset
3. Select from various analysis options:
   - **Descriptive Analysis**: View summary statistics and correlations
   - **Regression**: Predict continuous values with linear regression
   - **Classification**: Classify data points with random forest
   - **Outliers**: Detect anomalies using z-score analysis
4. View interactive visualizations and results

## Note

The backend uses in-memory storage, so uploaded datasets are temporary and will be lost when the server restarts. This is designed as a proof of concept for data analysis capabilities.
